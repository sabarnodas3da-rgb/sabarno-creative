# Sabarno Das – Portfolio
1. Install Node.js (LTS) from nodejs.org.
2. Open this folder in VS Code, open Terminal, run: npm install
3. Copy .env.example to .env.local and fill it in.
4. Run: npm run dev  -> open http://localhost:3000
5. Edit your links in lib/config.ts
6. Deploy: push to GitHub, import the repo at vercel.com, add the same env variables, click Deploy.
